# WaitLess Marketing Assets

This folder contains presentation and promotional video assets for the WaitLess digital queue management system.

## Deliverables

- `WaitLess_Presentation.pptx` — 14-slide, 10-minute presentation with speaker notes.
- `WaitLess_Promo_1080p.mp4` — 2-minute, 1080p marketing video with motion graphics and background music.

## How to regenerate

The assets are generated by Python scripts in `scripts/`.

```bash
# Create a virtual environment and install dependencies
python3 -m venv /tmp/wl-venv
/tmp/wl-venv/bin/pip install python-pptx pillow numpy

# Build the PowerPoint
/tmp/wl-venv/bin/python scripts/build_presentation.py

# Render the video (requires ffmpeg)
/tmp/wl-venv/bin/python scripts/make_promo.py
```

## Notes

- The video is rendered at 1920x1080, 24 fps, ~120 seconds.
- Background music is synthesized procedurally; no external audio assets are required.
- Fonts used: Inter (system-installed). If Inter is unavailable, the scripts will fall back to default PIL fonts.
